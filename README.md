# Veltrix Yield Vault

Veltrix Yield Vault is a Web3 vault application built on OPN Testnet.

The project combines wallet connectivity, smart contracts, and a gamified points system to create an engaging DeFi experience. Users can connect wallets, view on-chain vault information, track deposits, monitor points, and compete through leaderboard mechanics.

## Features

* Wallet Connect integration using RainbowKit and Wagmi
* Custom OPN Chain configuration
* Deployed VeltrixVault smart contract
* User deposit tracking
* User points system
* Ranking and leaderboard architecture
* Responsive dashboard interface
* Mobile-friendly design
