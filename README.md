# Veltrix Yield Vault

Veltrix Yield Vault is a Web3 application built on OPN Testnet that transforms simple vault participation into an on-chain reputation experience.

Users can connect their wallets, deposit OPN into a smart contract vault, earn points over time based on vault activity, track performance through a realtime dashboard, and compete on a transparent on-chain leaderboard.

## Features

* Wallet Connect integration using RainbowKit and Wagmi
* Custom OPN Testnet configuration
* Verified VeltrixVault smart contract
* Realtime wallet balance tracking
* On-chain deposit and withdrawal transactions
* Time-based points system
* Realtime leaderboard ranking
* Live protocol statistics
* Transaction explorer integration
* Responsive dashboard interface
* Mobile-friendly design

## Core Functionality

### Deposit

Users can deposit OPN into the vault through direct smart contract interaction.

### Withdraw

Users can withdraw deposited OPN at any time.

### Points System

Points are earned automatically over time based on deposited OPN balances.

### Leaderboard

Users compete based on accumulated points, creating a simple on-chain reputation system.
